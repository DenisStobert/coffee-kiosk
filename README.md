# Coffee Kiosk UI ☕

Тестовое задание на вакансию Full Stack разработчика систем самообслуживания.

## 🚀 Демо

[Открыть онлайн](https://your-deploy-link.vercel.app)

## 🧠 Описание

Мини-приложение имитирует работу терминала самообслуживания в кофейне.

Реализован пользовательский сценарий:
- Выбор напитка и его объёма
- Выбор способа оплаты (наличные или банковская карта)
- Эмуляция оплаты и обработки транзакций
- Анимация приготовления напитка
- Обработка успешных и неуспешных операций с выдачей результата

Проект построен с использованием:
- **React**
- **CSS Modules / CSS files**
- Эмулятор (`emulator.js`) для симуляции работы оборудования

## 🔧 Установка и запуск

```bash
git clone https://github.com/yourusername/coffee-kiosk.git
cd coffee-kiosk

```

## ⌨️ Эмуляция

### 💳 Оплата банковской картой

| Клавиша | Описание            |
|---------|---------------------|
| `X` или `Ч` | Успешная транзакция |
| `Y` или `Н` | Ошибка транзакции   |

### 💵 Оплата наличными

| Клавиша | Купюра |
|---------|--------|
| `1`     | 10 ₽   |
| `2`     | 50 ₽   |
| `3`     | 100 ₽  |

### ☕ Эмуляция выдачи напитка

| Клавиша | Результат         |
|---------|-------------------|
| `Y` или `Н` | Напиток выдан     |
| `X` или `Ч` | Напиток не выдан  |
